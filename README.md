# My Portfolio

A full-stack developer portfolio built with the PERN stack.

## Technology

- React
- TypeScript
- Tailwind CSS 4
- Node.js
- Express
- PostgreSQL
- Drizzle ORM

## Project Structure

- client: Frontend application
- server: Backend application
- docs: Technical documentation

## Requirements

- Node.js 26+
- npm
- PostgreSQL

## Installation

Clone the repository and install dependencies:

npm install

## Environment Setup

Refer to the respective .env.example files.

## Development

Start both applications:

npm run dev

Frontend:
http://localhost:5173

Backend:
http://localhost:5000

API health:
http://localhost:5000/api/health

## Available Scripts

npm run dev
npm run build
npm run typecheck
npm run lint
